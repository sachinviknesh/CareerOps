# 3. PRODUCT CONCEPT

The application solves one simple problem:

A student or early-career candidate applies to many different opportunities and has difficulty knowing:

1. What opportunities they found
2. What they still need to apply for
3. What stage each application is in
4. Which skills the opportunity needs
5. Which skills they already have
6. Which skills are missing
7. Whether their resume supports the requirements
8. What should be improved before applying

The application therefore has two main areas:

### A. Opportunity Tracker

Track:

* Job
* Internship
* Hackathon
* CTF
* Other

### B. Job-Fit Analyzer

Compare:

**Candidate profile + candidate skills + extracted resume text**

against:

**Opportunity title + description + required skills + experience + education + location/work mode where available**

Return an explainable result rather than a mysterious number.

# 17. OFFLINE JOB-FIT ALGORITHM

Do NOT depend on AI for the base score.

Implement a transparent deterministic algorithm.

### A. Skill match

Normalize:

```text
lowercase
trim whitespace
remove punctuation
normalize common separators
```

Compare candidate skills with opportunity required skills.

Produce:

```text
matchedSkills
missingSkills
```

Example:

```json
{
  "matchedSkills": [
    "Java",
    "Spring Boot",
    "MySQL"
  ],
  "missingSkills": [
    "Docker",
    "Kubernetes"
  ]
}
```

Never invent skills.

---

### B. Resume evidence

Check whether required skills also appear in resume text.

This distinguishes:

```text
candidate has skill selected
```

from:

```text
candidate has actual resume evidence
```

---

### C. Description/resume similarity

Implement a lightweight local text similarity method.

Use:

```text
tokenization
term frequencies
inverse document frequency
cosine similarity
```

Do NOT add a vector database.

Do NOT add embeddings for the base implementation.

This provides a meaningful offline NLP feature with relatively little code.

---

### D. Experience comparison

Attempt to extract a stated experience requirement from the job description.

Example:

```text
2+ years
3 years experience
```

Compare against:

```text
Candidate.experienceYears
```

If a requirement cannot be identified:

```text
UNKNOWN
```

Do not automatically fail the candidate.

---

### E. Education comparison

Compare the opportunity's education wording with the candidate's education text.

Return:

```text
MATCH
PARTIAL
UNKNOWN
```

Do not assume that one degree automatically makes someone eligible unless the text clearly supports it.

---

### F. Resume quality signals

Add signals from the offline resume analysis.

```text

```

**Public recruiting guidance and recruiter/interview material used to inform the application's analysis.**

The application should incorporate the following evidence-based themes:

### Role alignment

The resume and candidate profile should clearly correspond to the target role.

### Skills

Relevant technical skills should be clearly represented.

### Experience and projects

Projects should demonstrate actual technical work rather than just listing technologies.

### Measurable evidence

Where truthful, achievements should describe measurable outcomes.

### Standard terminology

Use generally understood industry terminology.

### Parser-friendly resume

Prefer clean, text-based DOCX/PDF structure.

### Clear job titles

Use descriptive industry-understandable titles.

### Reverse chronological experience

Use conventional experience ordering.

### Technical + behavioral preparation

Technical roles can involve both technical assessment and behavioral evaluation.

These ideas are supported by public Microsoft, Amazon, NVIDIA and recruiter material.

Do not claim:

```text
Google uses exactly this score.
Amazon uses exactly this score.
```
