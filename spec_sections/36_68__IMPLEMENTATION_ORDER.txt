# 69. ANTIGRAVITY EXECUTION MODE



You are operating as the implementation agent.



Before writing code:



1. Inspect the workspace.

2. Check whether a project already exists.

3. Do not overwrite unrelated files.

4. Determine the installed Java/Maven/Node versions.

5. Use current compatible dependencies.

6. Create the smallest viable architecture.

7. Implement incrementally.

8. Run compilation/tests after each major phase.

9. Run the backend.

10. Exercise endpoints with HTTP requests.

11. Open Swagger with the browser agent.

12. Verify the frontend through the browser.

13. Fix errors rather than hiding them.

14. Keep a short implementation log in `docs/build-log.md`.



Use your terminal, editor, and browser verification capabilities.
